Website Editing Guide
How to Edit Kraapht Bags Website
Without Touching HTML
One file. One change. Live in 60 seconds. This guide shows you exactly how to update prices, contact details, and text using GitHub — no developer needed.

How it works in 3 steps

1
You open config.js on GitHub and make a change
All prices, minimum quantities, contact details, and key text live in one file called config.js. It is plain text — you can read and edit it like a shopping list.
2
You click "Commit changes" on GitHub
That is the save button. One click. GitHub saves your change and automatically tells Vercel that the file has been updated.
3
Vercel rebuilds and your live site updates in ~60 seconds
Every customer who visits the website after that sees the new price or text. No downloading, no uploading, no FTP. Just GitHub.

How to update a paper price

Kraft paper prices change with the market. Here is exactly what to do when they do.

Scenario: Chromo Coat goes from GHS 525 to GHS 580
1
Go to github.com and open your Kraapht repository
Sign in → click your repository name (e.g. kraapht-bags)
2
Click on the file config.js
It is in your main file list. Click the filename to open it.
3
Click the pencil icon (top right of the file)
This opens the GitHub text editor. You can now edit the file directly in your browser.
4
Find the line for Chromo Coat and change the number
Use Ctrl+F (or Cmd+F on Mac) to search for chromo_coat. Find this section:
// BEFORE (old price) paper_prices: { chromo_coat: 525, // White / Chromo Coat brown_card_250: 550, ... }
Change 525 to 580:
// AFTER (new price) paper_prices: { chromo_coat: 580, // White / Chromo Coat ← updated brown_card_250: 550, ... }
5
Scroll down and click "Commit changes"
A dialog appears. You can leave the message as-is or type "Updated Chromo Coat price to GHS 580". Click the green Commit changes button. Done. Vercel deploys in ~60 seconds.

How to update contact details

Scenario: Phone number changes

Open config.js → pencil icon → find the contact section → change the number → commit.

contact: { whatsapp_number: "233558619224", // No + or spaces whatsapp_display: "+233 558 619 224", // How it shows on screen email: "kraaphtbags@gmail.com", },
Important: whatsapp_number must have no spaces, no +, no dashes — just digits. whatsapp_display is what customers see written on screen and can be formatted however you like.

How to change minimum order quantity

If you want to increase or decrease the minimum order from 200 to a different number:

order: { minimum_qty: 200, // ← change this number only delivery_cost: 30, ... },

The order page, all text showing "minimum 200 bags", and the price calculator minimum all update automatically.

How to change an image on the website

1
Prepare your new image
Name it exactly the same as the image you are replacing. For example, if you want to replace the AL Lounge photo, name your new file lifestyle_alounge.png
2
Go to your GitHub repository
Open the repository → click Add file → click Upload files
3
Drag your new image into the upload area
GitHub will ask if you want to replace the existing file. Confirm yes.
4
Click "Commit changes" — done
Vercel redeploys and your new image is live in ~60 seconds. Same filename = no HTML changes needed.

3 rules — never break these

!
Only change values — never change key names
In chromo_coat: 525 — you can change 525. Never change chromo_coat. The website reads the key names exactly as written.
!
Keep commas where they are
Every line in config.js ends with a comma. If you accidentally delete a comma, the calculator may stop working. If something breaks, come back here and I will fix it in minutes.
!
Text values need "quotes" — numbers do not
minimum_qty: 200 — no quotes needed for numbers.
email: "kraaphtbags@gmail.com" — quotes required for text. Keep them exactly as they are.
Something broke? Don't panic. GitHub keeps the full history of every change you have ever made. You can click on any previous version and restore it with one click. And you can always share the error here and I will fix it immediately.
